# Skillz Directory — Services Page

## Files
- `index.html`: Page structure and content.
- `styles.css`: Responsive styles and layout.
- `script.js`: Sample listings, search/filter behavior, provider details, live-chat preview, dialogs, and mobile menu.

## Run
Open `index.html` in a browser. The page uses Google Fonts over the internet.
The sample provider photos are referenced under `assets/` in the original HTML. If those images are not available, the page falls back to provider initials.

## Notes
The live chat is a front-end preview only. Messages are not saved or delivered to a real provider; production live chat needs a backend or messaging service.
